# Severity

How serious an alert is, used to route and prioritise notifications

## Example Usage

```python
from formance_sdk_python.models.reconciliation import Severity

value = Severity.INFO
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `INFO`     | info       |
| `LOW`      | low        |
| `MEDIUM`   | medium     |
| `HIGH`     | high       |
| `CRITICAL` | critical   |
